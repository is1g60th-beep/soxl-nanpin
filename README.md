# SOXLナンピン購入管理アプリ

SOXLの5段階のナンピン買い（総予算100万円）を管理するPWAです。株価・USD/JPY・週足RSIを自動で取得し、楽天証券の円貨決済で手数料を含めて買える最大株数を計算します。**自動発注はしません。**

```
（直下）  … Webアプリ本体（GitHub Pagesで配信）
  index.html / app.js（画面）/ core.js（計算ロジック）/ sw.js / manifest / アイコン
worker/   … APIキーを預かる中継サーバー（Cloudflare Workers）※Pagesでは使われない
tests/    … 必須テスト20件＋追加テスト（node --test tests/core.test.js）
scripts/  … ブラウザでの動作確認（モックAPI）
```

## 1. 構成と理由

| 役割 | 採用 | 理由 |
|---|---|---|
| 画面 | GitHub Pages（静的PWA） | 無料、iPhone/iPadでホーム画面に追加できる |
| APIキー管理 | Cloudflare Workers（無料枠） | GitHub Pagesだけではキーを隠せない。キーはWorkerのシークレットに保存し、アプリには渡さない |
| 株価 | Finnhub `/quote`（失敗時はTwelve Data） | 無料で60回/分。米国市場の開場状況（`/stock/market-status`）も取得できる |
| 為替・週足 | Twelve Data `/quote`, `/time_series?interval=1week` | 無料のBasicプランでUSD/JPYと米国株を扱える（8回/分・800回/日） |
| データ保存 | 端末内（localStorage）＋JSONバックアップ | 一人で使う前提。端末間の同期は今後の拡張（下記） |

Workerでキャッシュ（株価15秒・為替60秒・週足1時間）するので、複数の端末で開いても無料枠の上限を超えにくくしています。既定の更新間隔は株価30秒・為替180秒・週足60分で、為替の取得は1日最大約480回です。

## 2. セットアップ（スマホ・タブレットだけで可能）

1. **APIキーを取得**（どちらも無料・カード登録不要）
   - Finnhub: https://finnhub.io/register
   - Twelve Data: https://twelvedata.com/register
2. （このリポジトリにはアプリ一式が入っています）
3. **GitHub Pagesを有効化**（無料プランではリポジトリをPublicにする必要があります）：Settings → Pages → Source「Deploy from a branch」→ `main` / `(root)` → Save。数分後に `https://ユーザー名.github.io/リポジトリ名/` で開けます。
4. **Cloudflare Workerを作成**：Cloudflareダッシュボード → Workers & Pages → Create → 「Hello World」を作成 → Edit code に `worker/worker.js` を貼り付けて Deploy。
   - Settings → Variables and Secrets に以下を登録：
     - `FINNHUB_KEY`（Secret）
     - `TWELVEDATA_KEY`（Secret）
     - `APP_TOKEN`（Secret・**必須**。自分で決めた長い合言葉。未設定だとWorkerは動きません）
     - `ALLOWED_ORIGIN`（Text・例 `https://yourname.github.io`）
   - PCがある場合は `cd worker && npx wrangler deploy` でも同じことができます。
5. **アプリの設定画面**で、WorkerのURL（`https://xxx.workers.dev`）と `APP_TOKEN` を入力し、「接続テスト」→「設定を保存」。
6. Safariの共有メニューから「ホーム画面に追加」。通知を使う場合は、追加したアプリから「通知を許可」。

APIを設定しなくても、「手入力」モードで株価・為替・RSIを入力して計算・記録ができます。

## 3. 計算ルール（実装済み）

- **投入可能額** ＝ min（その回までの基本枠の合計 − 実際の受渡金額の合計, 総予算 − 実際の受渡金額の合計）
  → 使い残しや見送った回の枠は自動で繰り越され、総予算を超えることはありません。
- **購入可能株数**：手数料込みの総支払見込額が投入可能額を超えない最大の整数。最後に「n株なら収まり、n+1株なら超える」ことを確かめ、確かめられなければエラーにします。
  - 手数料 ＝ 約定代金 × 0.495%（セント未満は切り上げ）。最低0ドル、上限22ドル。
  - 適用為替レート ＝ 市場レート ＋ 0.25円。楽天の適用レートを手入力した場合はその値を使います。
  - 総支払見込額 ＝ (約定代金 + 手数料) × 適用レート（1円未満は切り上げ）＋ その他費用
- **目標価格** ＝ 直前の**実際の約定価格** ×（1 − 下落率）。試算の価格や、目標に届いただけの価格を基準にすることはありません。
- **段階を進める条件**は「購入実績を登録したとき」だけです。条件に届いても買わなかった場合は、同じ条件を見続けます。どうしても1回飛ばしたい場合に限り、確認つきの「見送って次の回へ」を用意しています（初回は飛ばせません）。
- **RSI**：14週のWilder式で計算します。**確定値**（前の金曜16時（NY時間）までに終わった週足）と**暫定値**（いま形成中の週足）を分けて表示し、購入条件の判定には確定値だけを使います。
- **データの鮮度**：状態を リアルタイム／遅延／時間外／休場／更新停止／エラー に分けて表示します。取引時間中に5分以上更新のない株価や、30分以上更新のない為替、取得に失敗したデータでは**計算を止めます**。手入力の値は120分で無効になります。
- **到達履歴**：条件に届いた時刻と、そのあと反発した時刻を記録します。到達したままの間は二重に記録しません。反発後の表示方法は設定で切り替えられます。

## 4. 未検証・要確認事項（確定した仕様ではありません）

1. **楽天証券の端数処理**：手数料のセント未満と、円換算の1円未満の扱い方は公式情報で確認できていません。安全側として**切り上げ**にしています（設定で変更できます）。初回購入後、実際の受渡金額と見比べて調整してください。
2. **円貨決済の為替手数料25銭**：楽天証券の解説ページに「円貨決済は1米ドルあたり25銭」とあります。変更される可能性があるため、注文直前は「楽天適用レート」の手入力をおすすめします。
3. **手数料無料の対象**：楽天証券は「当社が指定する銘柄の買付手数料は無料」としています。SOXLが対象かは指定銘柄の一覧で確かめてください。新規口座開設者向けの「最大2か月 手数料無料」プログラムもあります。当てはまる場合は設定で「手数料無料」をオンにします。
4. **Finnhub無料プランのリアルタイム性**：60回/分で米国株の気配が取れるという情報が多い一方、「リアルタイムには有料の申請が必要」とする情報もあり、確定できていません。アプリはデータの時刻から遅延を判断して表示するので、遅延していれば表示でわかります。**売気配（Ask）は無料プランでは取れない**ため、最終取引価格で計算しています（Askが取れる有料APIに替えれば自動でAskを使います）。
5. **米国株の23時間取引（2026年12月7日開始予定）**：オーバーナイトのセッションを各APIがどう返すかは未確認です。不明なセッションは「時間外」として扱います。
6. **Twelve Data週足の日付**：週の初日の日付を想定し、月曜に直してから確定・暫定を判定しています。実データで要確認です。
7. **プッシュ通知**：アプリを開いている間のみ通知します。アプリを閉じている間も通知するには、Workerの Cron Triggers と Web Push（VAPID）を追加する必要があります（今後の拡張）。

## 5. 相場環境（参考指標）と週末チェックリスト

資料「VIXとSOXL：2つの話を合わせた相場の見方（2026年11月）」のシグナル一覧をホーム画面に表示します。**購入条件の判定には使わない参考情報**です。

| 指標 | 取得方法 | 示すもの |
|---|---|---|
| VIX（29突破かつS&P500が8%以上下落） | 自動（FREDの日次終値）／日中の値は手入力 | 下落継続 |
| S&P500 高値からの下落率 | 自動（SPY日足で代用） | 20%未満は「待ち」、20%で買い場の前提 |
| SOXL 週足RSI（確定） | 自動 | 30以下で買い条件 |
| 半導体 週足RSI | 自動（SOX指数の代わりにSOXX） | 30付近で底の目安 |
| SOXL 日足の強気ダイバージェンス | 手入力 | 発生中は反発、消滅は下落継続 |
| ZBT インジケーター | 手入力 | 0.40未満は売られすぎ、発動で反発 |

- 自動取得にはWorkerの `/api/market` を使います（Twelve Dataの利用枠を1時間に2回分消費）。**この機能を使うには、最新の `worker/worker.js` をCloudflareに貼り直してください。**
- SPYは配当で値が下がる分があるため、S&P500指数の下落率とはわずかにずれます。SOXXはSOX指数（PHLX）ではなくNYSE半導体指数に連動するETFなので、RSIの値は資料と完全には一致しません。
- **VIX**：Workerの `/api/vix` が、FRED（米セントルイス連銀）の日次終値 `VIXCLS`（Cboe算出）を取得します。値は前営業日の終値で、アプリは1時間ごとに確認します。日中の値を使いたいときは手入力でき、手入力のほうが新しければ手入力を使います。取得元は画面に表示されます。
  - Cboeの公開データは、サーバーからのアクセスを拒否（HTTP 403）するため使っていません。
  - FREDのキーは https://fredaccount.stlouisfed.org で無料登録 →「API Keys」→「Request API Key」で取得し、Workerのシークレット `FRED_KEY` に登録します（英小文字と数字の32文字）。
- 週末チェックリストは資料の「これから見ておくこと」6項目です。チェックは週ごとにリセットされます。

## 5-2. セキュリティ対策

- **APIキー**：Workerのシークレットにのみ保存し、データ提供元へは**URLではなくヘッダー**で送ります（Finnhub: `X-Finnhub-Token`、Twelve Data: `Authorization: apikey`）。
- **Workerの呼び出し制限**：`APP_TOKEN` を必須にしています。比較は、所要時間から合言葉を推測されない方式です。
- **バックアップ**：JSONにはアプリトークンを含めません（変更履歴の中からも削除します）。
- **復元時の検証**：読み込んだデータは、型と形式をチェックしてから使います。不正な値を含む購入記録は拒否します。**API中継URLとトークンはファイルの値を使わず、端末の現在値を維持します**（偽の価格を出す中継先に差し替えられるのを防ぐため）。
- **画面表示**：利用者が入力した文字列は、すべて無害化してから表示します。
- **利用者側でお願いしたいこと**：GitHub・Cloudflare・Finnhub・Twelve Dataで2段階認証を有効にすること。他人から受け取ったJSONは復元しないこと。このアプリが楽天証券のログイン情報を求めることはありません。

## 6. 今後の拡張（任意）

- **端末間の同期**：Cloudflare KVかD1に保存し、Cloudflare Accessなどで認証する。
- **閉じている間の通知**：Cron Triggers で5分ごとに条件を判定し、Web Pushで知らせる。
